# Recruiter and freelance-client walkthrough

## What to show first

For cloud-security roles, start with Security Investigation Copilot and Evidence
Desk. For freelance business automation, start with Invoice Check, CaseFlow and
Meeting to Momentum. Contract Radar connects with contract lifecycle workflows;
Proposal Studio shows how a client brief becomes a scoped technical plan.

## Five-minute walkthrough

1. Name the business problem and identify the synthetic data.
2. Run an example, edit the input and show what changes.
3. Inspect evidence, intermediate artifacts and the workflow trace.
4. Show a failing input or rejected tool call in the test suite.
5. Explain the Foundry connection and clearly state whether it has been run live.

The strongest interview discussion is a design decision you can explain: why invoice
totals are recomputed, why a model cannot choose another customer's order, why a
citation check is useful but incomplete, or how a notice deadline is calculated.

## Accurate CV wording for the current state

AI Application Portfolio — Python, Microsoft Foundry SDK, Responses API

Prepared seven AI-assisted application prototypes covering cited knowledge retrieval,
tool-calling support and security workflows, invoice validation, contract renewal
review, proposal drafting and meeting action extraction. Implemented deterministic
checks and 69 automated tests, with editable browser demos and an optional Foundry
integration. Offline workflows verified; live Azure validation pending.

Do not turn this into a production deployment, commercial-results or independent
authorship claim. After running it yourself, record the changes and decisions you
made. After genuine cloud verification, update that specific sentence with evidence.

## Before accepting a client project

Agree on the problem, representative inputs, success criteria, access permissions,
human review points and expected operating costs. Demonstrate failures as well as
successful examples. Use the portfolio to explain an approach, then scope the real
client integration separately.
